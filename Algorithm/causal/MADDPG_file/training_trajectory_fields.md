# 训练轨迹 CSV / JSON 字段说明

`MADDPG.py` 默认会写出 `training_trajectory.csv`（可加 `--no_save_trajectory` 关闭）。每一行对应**环境的一步**；前几列是公共信息，后面每个智能体一列，单元格内是一段 **JSON**（一个对象，不是数组）。

## CSV 表头（公共列）

| 列名 | 含义 |
|------|------|
| `episode` | 当前回合编号（从 0 起算） |
| `global_step` | 训练全局步计数（与代码里写入的一致） |
| `episode_step` | 本回合内第几步（从 0 起算） |
| `agent_0`, `agent_1`, … | 该步下对应智能体的转移，**整格为 JSON 字符串** |

解析时：对某一格做 `json.loads(单元格)`，得到下表中的对象。

---

## JSON 对象内各字段

| 字段 | 类型 | 含义 |
|------|------|------|
| `agent_id` | 字符串 | 智能体 id，如 `"agent_4"` |
| `obs_dim` | 整数 | 观测向量维度，应与 `obs` 长度一致 |
| `action_dim` | 整数 | 动作向量维度，应与 `action` 长度一致 |
| `obs` | 浮点数组 | **本步动作前**的环境观测（按环境固定顺序排成一串数） |
| `action` | 浮点数组 | 策略网络输出的动作（约 \([-1,1]\)），**写入时未含探索噪声、也未映射到 \[0,1\]**；真正进环境的是另一条支路（噪声 + 映射） |
| `reward` | 浮点数 | 本步环境给该智能体的即时奖励 |
| `terminated` | 布尔 | 是否因任务规则结束本回合 |
| `truncated` | 布尔 | 是否因达到最大步数等原因被截断结束 |
| `done` | 布尔 | `terminated \|\| truncated`，本步后是否视为回合结束 |
| `next_obs` | 浮点数组 | **本步执行后**的下一时刻观测 |

`obs`、`next_obs`、`action` 写成**列表**，表示环境/网络里的**向量**：第 0、1、2… 个元素是不同分量，具体物理含义以 **环境文档 / 观测定义** 为准；轨迹只保证顺序与环境一致。

---

## 补充

- 需要「与 `env.step` 完全一致的动作」时，要在代码里另外序列化环境侧动作；当前文件未包含。
- 扁平宽表格式见 `--trajectory_format main_like` → `training_trajectory_main_like.csv`。
