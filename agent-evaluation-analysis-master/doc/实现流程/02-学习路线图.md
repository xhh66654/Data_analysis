## 2. 进度 Checklist

### 环境准备
- [ ] 安装 Python 3.9+（建议 conda 或 venv）
- [ ] `pip install gymnasium[box2d] torch numpy pandas scikit-learn matplotlib graphviz`

- [ ] 克隆/解压仓库到**无中文/无空格**的路径（避免 `graphviz.render` 失败）

## 4. 遇到问题怎么办

1. **先看本目录 README 的第 6 节（5 个坑）**
2. **去 `docs/<子目录>/<文件名>.py.md` 查该文件的自动说明**
3. **去 `docs/00-项目整体文档索引.md` 做宏观定位**
4. 仍然卡住 → 打印错误的完整 traceback，把**最后一行错误类型**（如 `ModuleNotFoundError: No module named 'box2d'`）当搜索关键词
