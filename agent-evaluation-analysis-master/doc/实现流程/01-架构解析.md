## 1. 架构分层：一张图看清数据流

```
┌─────────────────────────────────────────────────────────────────────┐
│                         【L1 · 环境层】                               │
│   gymnasium 的 CartPole-v1 / LunarLander-v2                          │
│   提供 state、接收 action、返回 reward                                 │
└─────────────────────────────────────────────────────────────────────┘
                ▲ state                   │ action
                │                         ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      【L2 · 智能体层（黑盒）】                         │
│   causal/DQN.py  —  Duel Double DQN 网络 + 经验回放                   │
│   训练入口：causal/main.py                                            │
│   产物：  model/*.pth（权重）                                         │
└─────────────────────────────────────────────────────────────────────┘
                │ 生成轨迹                 │ 提供 Q 值/动作
                ▼                         ▼
┌──────────────────────────────┐  ┌──────────────────────────────────┐
│   【L3a · 数据层】            │  │   【L3b · 溯因分析层】              │
│   causal/generate_trajectory │  │  反事实：casual-LLV2-1.py           │
│   *.py  →  trajectory_*.txt  │  │  扰动/梯度：test715.py              │
│           training_data_*.xlsx│  │                                  │
└──────────────────────────────┘  └──────────────────────────────────┘
                │
                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                    【L4 · 可解释蒸馏层（白盒）】                       │
│   DT/datatest814*.py  —  sklearn DecisionTreeClassifier              │
│   产物：decision_tree*.pdf（可视化）                                   │
│         decision_tree_nodes*.xlsx（节点规则表）                        │
└─────────────────────────────────────────────────────────────────────┘
                │
                ▼
          人类可读的 if-then 规则  ←  研究目标：从黑盒到白盒
```

**一句话总结架构：**
> L1 环境 ⇄ L2 黑盒策略 → L3a 产生数据 / L3b 从黑盒做归因 → L4 用决策树把黑盒"翻译"成白盒。

## 2. 每一层的"代码锚点"

初学者常迷路于"这个概念对应哪段代码"。下面给你精确定位。

### L1 · 环境层

| 概念 | 代码位置 |
|---|---|
| 创建环境 | `Algorithm/causal/main.py:42` → `gym.make(EnvName[opt.EnvIdex], ...)` |
| 状态/动作维度 | `Algorithm/causal/main.py:44-46` |
| 交互一步 | `Algorithm/causal/main.py:97` → `env.step(a)` |

### L2 · 智能体层

| 概念 | 代码位置 |
|---|---|
| 训练主循环 | `Algorithm/causal/main.py:85-117` |
| 智能体初始化 | `Algorithm/causal/main.py:76` → `DQN_agent(**vars(opt))` |
| 选动作（ε-greedy） | `Algorithm/causal/DQN.py` → `select_action` |
| 网络结构（Duel / Double） | `Algorithm/causal/DQN.py` → `Q_Net` 类 |
| 经验回放 | `Algorithm/causal/DQN.py` → `ReplayBuffer` 类 |
| TD 目标 + 反向传播 | `Algorithm/causal/DQN.py` → `train()` 方法 |
| 保存/加载权重 | `Algorithm/causal/DQN.py` → `save/load` |

> **读代码顺序建议：** `main.py`（看流程）→ `DQN.py` 的 `__init__` → `select_action` → `train` → `Q_Net.forward`。

### L3a · 数据层

| 概念 | 代码位置 |
|---|---|
| 加载训练好的模型 | `Algorithm/causal/generate_trajectory (1).py` 开头的 `agent.load(...)` |
| 滚动一局收集轨迹 | 同文件 while 循环 |
| 保存为 txt / xlsx | 同文件末尾 `np.savetxt` / `pandas.to_excel` |

### L3b · 溯因分析层

| 概念 | 代码位置 |
|---|---|
| 反事实：选"次优动作"重新 rollout | `Algorithm/causal/casual-LLV2-1.py` |
| 扰动法：对 state 每一维加噪声观察 Q 变化 | `Algorithm/causal/test715.py` |
| 说明文档 | `docs/causal/因果与强化学习-溯因分析包.md` |

### L4 · 可解释蒸馏层

| 概念 | 代码位置 |
|---|---|
| 读入状态-动作数据 | `Algorithm/DT/datatest8141.py` 开头 `pd.read_excel(...)` |
| 归一化 | `Algorithm/DT/calculate_stats.py` |
| 训练决策树 | `datatest8141.py` → `DecisionTreeClassifier(...).fit(X, y)` |
| 导出 PDF | 同文件 → `graphviz.Source(...).render(...)` |
| 导出节点表 | 同文件 → 遍历 `tree_.feature / tree_.threshold` |

## 3. 配置/产物对照表

| 你运行了什么 | 它会读什么 | 它会写什么 |
|---|---|---|
| `causal/main.py --EnvIdex 0` | 无（在线与 gym 交互） | `model/DuelDDQN_CPV1_*.pth`（每 50k 步一份） |
| `causal/generate_trajectory (1).py` | `model/*.pth` | `trajectory_*.txt`（根目录） |

**不要手动改 `model/*.pth` 的文件名！** 加载逻辑依赖固定的命名规则（`{algo}_{env}_{step/1000}.pth`），改了就加载不到。

## 4. 从"看代码"到"跑实验"的最小闭环

给自己定一个目标：**生成一棵能跑的决策树**。步骤：

```
[1] 训练 DQN          →  python causal/main.py --EnvIdex 0 --Max_train_steps 100000
[2] 生成轨迹数据      →  python causal/generate_trajectory\ \(1\).py   # 手动把产物整理成 xlsx
[3] 训练决策树        →  python DT/datatest8141.py
[4] 打开产物看效果    →  decision_tree.pdf
```

走完这条路，你就**亲手走了一遍"黑盒 → 数据 → 白盒"的完整流程**——而这正是本仓库的研究目的。

## 5. 常见疑问

**Q1: `causal/` 里为什么有好几个 `generate_trajectory*.py`？**
A: 是同一脚本的不同迭代版本。以 `generate_trajectory (1).py` 为最新/可运行版本，其它是历史稿。

**Q2: `MADDPG_file/` 和主线什么关系？**
A: 弱关系。它是"多智能体"方向的探索性代码，和"单智能体 DQN + 溯因"是两条独立实验线。**初学者先完全跳过**。

**Q3: `FreeRL-main/` 需要读吗？**
A: 不需要。是第三方参考库，作者放进来做算法对照。除非你要复现某个特定算法（PPO/SAC），否则不看。

**Q4: 决策树的准确率不高怎么办？**
A: 这是"蒸馏"固有的 trade-off —— 可读性 vs 精度。可调 `max_depth`、`min_samples_leaf`，或增加训练数据量。

## 6. 进一步学习路径

- **强化学习理论**：Sutton & Barto《Reinforcement Learning: An Introduction》第 6 章（TD learning）、第 9 章（函数近似）。
- **DQN 原论文**：Mnih et al. 2015, "Human-level control through deep RL"。
- **Duel DQN**：Wang et al. 2016。
- **Double DQN**：van Hasselt et al. 2016。
- **反事实解释**：Madumal et al. 2020, "Explainable Reinforcement Learning Through a Causal Lens"。
- **策略蒸馏到决策树**：Bastani et al. 2018, "Verifiable Reinforcement Learning via Policy Extraction"。

读完这几篇，本仓库对你来说就是透明的。
