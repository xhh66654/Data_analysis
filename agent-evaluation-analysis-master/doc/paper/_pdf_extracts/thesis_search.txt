4.3.1 
强化学习模型 
强化学习是一种学习机制， 智能体通过学习在不同环境状态下采取最佳行动的策略
来最大化累积奖励。 在强化学习框架下， 智能体的决策过程被建模为马尔可夫决策过程。

4.3.2 基于 VIPER 算法的决策树构建 
可验证性策略提取算法 （Verifiability via Iterative Policy ExtRaction，VIPER） 的主要
思想是基于模仿学习的方法， 使用高性能的深度强化学习模型来指导训练， 最终将强化
学习模型策略提取成一个决策树策略[79]。 
模仿学习是一种监督学习的方法， 通过专家策略获得训练数据， 一般以观测值作为
输入数据，以产生的动作作为标签，通过设计损失函数，对参数化的策略函数进行迭代
学习。 
Dataset Aggregation (DAGGER)算法是经典的模仿学习算法， 在每轮的迭代过程中，
专家策略都会对当前策略采集的状态进行标记， 随后将这些新标记的数据整合到数据库
中， 用于重新训练策略网络
[80]。 通过这一机制， 策略网络学习到的策略分布将逐渐接近
数据库中的策略分布。 但是，DAGGER 算法忽略了一点， 专家网络不仅仅能指导策略网
络在当前状态下做出最佳操作， 还能够提供每个状态-动作对的累积奖励。 针对这一问题，

4.3.3 决策规则提取  
通过提取出来的决策树， 可以根据输入的态势信息得到适用的策略规则。 从决策树
的根节点出发。经过中间节点到叶子节点，这一条决策路径可以用 IF-THEN 的形式表
示出来，视作一条策略规则。决策树的每个叶子节点都代表一条具体的策略规则，假设
一棵决策树有 L 个叶子节点，那么就可以从中提取出 L 条决策规则，组成一个决策集
12{ , ,..., } LRule rule rule rule= 。 
决策树规则提取流程如算法 4.2 所示。首先，根据给定的决策树，以及可能的输出
格式， 初始化一个空的规则集合Rule ， 用于存储提取出的规则。 通过深度优先搜索 （DFS）
的方法遍历决策树的每个节点，对遍历到的节点生成一个部分规则， 如果当前节点为叶
子节点，则将其类别作为最终规则的一部分；如果节点为非叶子节点，则将节点的判断
条件包括特征和阈值添加到部分规则，并递归处理其左右子树。遍历完成后，获得提取
出的规则集合
Rule 。 
这样提取出的规则中， 可能存在很多冗余信息， 为了提高规则集的简洁性和泛化能
力， 减少冗余信息， 进一步对规则集进行合并。 遍历集合Rule ,对于每条规则 rule ，检 查
条件部分是否相似或存在包含关系。对于具有相似性的规则，将它们合并为一条更泛化
的规则。

2: 初始化条件相似性阈值 delta 
3: while 存在未处理的节点 do 
4:     获取下一个未处理的节点 Node 
5:     提取节点 Node 的条件部分作为条件 C 
6:     提取节点 Node 的类别部分作为类别 L

12:    end if  
13: end for
