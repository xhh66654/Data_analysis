## 0. 项目全景速览

原方案文档提出了 3 个递进的溯因技术：

| 模块 | 技术 | 一句话目标 |
| --- | --- | --- |
| 模块 A | **基于规则抽取**（VIPER + 决策树） | 把"黑盒"强化学习模型转换成一棵**可读的 IF-THEN 决策树** |
| 模块 B | **基于博弈约简**（SCM + 平均场） | 用因果权重把"N 个智能体"压缩成"中心 + 邻居"，再做溯因 |
| 模块 C | **基于反事实推理**（CEMA） | 回答"如果不这样做会怎样" — 生成自然语言因果解释 |

**最终产物**：一个模拟的"红蓝空战"环境 + 一套可对训练好的智能体解释行为的溯因系统（含可视化 + 自然语言解释）。

### 阶段 4 ── 模块 A：VIPER 规则抽取（2 周）

**核心思想**：用一棵决策树去"模仿"训练好的 DQN/PPO，然后把树翻译成 IF-THEN 规则。

#### 步骤（也是代码文件组织）
```
src/module_a/
├── collect_data.py      # 让 RL 模型跑环境，收集 (state, action)
├── preprocess.py        # 量纲归一化、离散化
├── viper.py             # VIPER 主循环
├── extract_rules.py     # DFS 遍历树 → 规则集
└── merge_rules.py       # 合并冗余规则
```

#### VIPER 算法（简化版伪代码）
```
输入：专家策略 π*（训好的 DQN）
数据集 D ← 用 π* 跑 N 条轨迹收集 (s, π*(s))
for i = 1..M:
    用 CART 在 D 上训决策树 π_i
    用 π_i 跑 N 条轨迹 → 得到新状态集 S_i
    对每个 s ∈ S_i，用专家 π* 打标签 → D_i
    根据"损失上界"重采样 D ∪ D_i
返回奖励最高的 π_i
```

对初学者友好的第一版：**跳过重采样**，直接用 `DAGGER` 思想循环 3-5 次就够出效果。

#### 规则提取
- `sklearn.tree.export_text` 可以直接拿到文本规则，但不美观
- 自己写 DFS 遍历树，节点上带 `特征名 + 阈值`，叶子带 `动作`
- 合并：两条规则除叶子外其他条件都一致且动作相同 → 合并

#### 验收标准
- 决策树策略在环境中的胜率 ≥ DQN 胜率的 80%
- 能打印出 5-10 条"人看得懂"的规则，类似文档例子：
  ```
  IF 相对X近 AND 弹药>2 THEN 攻击1号
  ```

- **特征重要性**：sklearn 的 `feature_importances_`、SHAP 值（选学）

├── counterfactual.py    # 生成 K 个反事实世界

关键能力：**环境要能存档/读档**！在 `AirCombatEnv` 里加两个方法：
```python
def get_state(self): return copy.deepcopy(self.__dict__)
def set_state(self, s): self.__dict__.update(copy.deepcopy(s))
```

#### 算法 1：反事实数据集生成（对应文档表 1）
```python
def generate_cf_dataset(env, policy, t_query, K=200):
    snapshot = env.get_state_at(t_query)
    dataset = []
    for k in range(K):
        env.set_state(snapshot)
        perturb(env)          # 微扰：某敌机位置 ±noise
        traj = rollout(env, policy)
        r = compute_reward(traj)
        flag = query_happened(traj)   # 目标行为是否出现
        dataset.append((traj, r, flag))
    return dataset
```

#### 算法 2：因果效应量（对应文档表 2）
- **目的论**（行为带来什么结果）
  - 查询出现样本的奖励均值 − 未出现样本的奖励均值，按维度排序
- **机械论**（什么导致了行为）
  - 拿状态特征预测 flag（是否发生该行为），看特征重要性

#### 自然语言输出模板
```python
templates = {
    "attack": "因为攻击{target}可以显著提高{r1}(+{v1:.2f})，同时降低{r2}",
    "evade":  "因为前方有{n_front}架敌机逼近，己方{n_side}架正在远离",
}
```

#### 验收标准
- 能对"EGO 为什么攻击 Red2 而非 Red1"给出合理回答
- 目的论、机械论两种解释都能输出
- 解释包含至少 2 个因果因素及其数值强度

### 阶段 6 ── 模块 B：SCM 博弈约简（3 周）— 最难

**只有前两个模块都稳了再来做这个。**

#### 预备补课
1. **平均场强化学习 MFRL**（3-4 天）
   - 论文：Mean Field Multi-Agent Reinforcement Learning (Yang et al. 2018)
   - 核心思想：中心体 i 的决策只依赖 "自己 + 邻居动作的平均"
   - 关键近似：`Q(s, a_i, a_{-i}) ≈ Q(s, a_i, ā_neighbor)`
2. **结构因果模型 SCM**
   - 三要素：外生变量 U、内生变量 V、结构方程 F
   - 用 **DAG（有向无环图）** 表示因果关系
   - Python 库：`networkx`（画图）、`dowhy` 或 `causal-learn`（进阶）
3. **KL 散度**
   - 公式：`KL(P‖Q) = Σ P(x)·log(P(x)/Q(x))`
   - 文档用它做**因果效应权重**：某邻居在/不在对中心策略分布的影响

#### 实现步骤
```
src/module_b/
├── scm.py               # 搭建 DAG：节点 = 智能体变量，边 = 因果依赖
├── causal_weight.py     # 用 KL 散度计算每个邻居的因果权重 w_j
├── merge_agents.py      # 加权合并邻居动作：ā = Σ w_j · a_j
├── reduced_mfrl.py      # 在"中心 + 虚拟平均体"上训练
└── abduction_on_reduced.py  # 在约简后的环境里跑模块 C 的 CEMA
```

#### 因果权重算法
```
对每个邻居 j：
  P_full      = π(·|s, 所有邻居)
  P_without_j = π(·|s, 邻居\{j})
  w_j ∝ KL(P_full ‖ P_without_j)
归一化 w_j 得到因果权重
```

#### 合并动作
文档公式（简化版）：
```
ā_neighbor = Σ_j  w_j · a_j     (w_j 归一化后)
```

#### 验收标准
- 20v20 场景：训练时间比普通多智能体 RL 降 ≥ 30%
- 用模块 C 对约简前 vs 约简后的解释做对比
- 约简后的解释更"简洁"（涉及智能体数量减少），且因果相关性更高

## 6. 关键算法速查（实现时再回来看）

### 6.1 VIPER（模块 A）
```
Input : 专家策略 π*, 环境 env, 迭代数 M, 每轮轨迹数 N
D ← ∅
for i in 1..M:
    D_i ← 用当前最佳树 π_i-1 采集 N 条轨迹的状态，用 π* 打标签
    D ← D ∪ D_i
    π_i ← CART.fit(D)             # 决策树
    记录 π_i 在环境中的回报
return argmax_i  reward(π_i)
```

### 6.2 CEMA（模块 C）
```
Input : 查询 q（"为什么 t 时刻做了动作 a"）, 策略 π, 环境 env, K
snapshot ← env.state_at(t)
dataset  ← []
for k in 1..K:
    env.restore(snapshot)
    perturb(env)                     # 扰动对手 / 外生变量
    τ ← rollout(env, π)              # 前向模拟
    R ← reward_vector(τ)             # 多维奖励
    f ← did_query_happen(τ, q)       # 0/1
    dataset.append((τ, R, f))

# 目的论：f=1 与 f=0 的奖励差
# 机械论：用 τ 的状态特征预测 f，取 feature_importances_
return  top_k 最有影响的因素
```

### 6.3 博弈约简（模块 B）
```
for 每个中心智能体 i:
    邻居 N(i) ← 视野内的智能体
    for j in N(i):
        P_full      ← π_i(·| s, a_{N(i)})
        P_drop_j    ← π_i(·| s, a_{N(i)\{j}})
        w_j ← KL(P_full ‖ P_drop_j)
    归一化 w
    ā ← Σ_j w_j * a_j              # 加权平均动作
用 (s, a_i, ā) 做 MFRL 训练
在约简后的环境上套用模块 C → 溯因解释更简洁
```

## 8. 风险与降级方案

| 风险 | 降级方案 |
| --- | --- |
| 自写空战环境 bug 多 | 先用 `gymnasium` 的 `SimpleMultiAgent` 或 `PettingZoo` |
| DQN 训练不收敛 | 用 `stable-baselines3` 的 PPO，开箱即用 |
| VIPER 决策树过拟合 | 限制 `max_depth=6`，或改用 `RandomForest` 的单棵 |
| SCM/因果图太难 | 模块 B 第一版用"距离权重"代替"KL 权重"，先跑通 |
| 反事实扰动无意义 | 先只扰动一个变量，确认 pipeline 通，再扩展 |
